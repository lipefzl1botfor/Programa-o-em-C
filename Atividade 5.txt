int main()
{
    int valor [3] [3];
    int soma = 0;
    
    printf("Por favor digite 9 valores inteiros para somar:\n ");
    
  for(int i= 0; i<3; i++){
      for(int j= 0; j<3; j++){
          printf("Por favor digite valor para posição [%d] [%d]: ", i,j );
          scanf("%d", &valor[i][j]);
          
          soma= soma + valor[i][j];
      }
      printf("\n---Seus Valores---\n");
  }
  
  for(int i = 0; i < 3; i++){
        for(int j = 0; j < 3; j++){
            printf("%d\t", valor[i][j]);
        }
        printf("\n");
    }
    
    printf("A soma de todos os valores equivale á: (%d)", soma);
    return 0;
}

5.1 Responda:
Qual é a diferença entre vetor e matriz?
Vetor trabalha com apenas uma dimensão, enquanto a Matriz trabalha com duas, sendo mais indicado para vários dados.

Quantos elementos possui uma matriz int dados[3][4]?
Essa matriz vai possuir 12 elementos, basta multiplicar o número de linhas pelo de colunas.

Por que normalmente utilizamos dois comandos for para percorrer uma matriz bidimensional?
Pois é necessário fornecer as informações para os elementos da linha [i] e depois outro para das colunas [j].
